# 인상 루브릭 (Perception Rubric) — 비교 금지 · 결핍 인상 금지

2026-08-21 제품 오너 지시로 신설. 부모/아동에게 보이는 모든 산출물(HTML·PDF)에 적용하며, `report-rubric.md`(R1~R9)와 별개로 **이 두 기둥만으로 100점 만점 채점**한다. 하나라도 어기면 100점 불가.

## P1. 비교 금지 (50점)

부모 화면 어디에도 이 아이를 다른 무언가와 견주는 요소가 없어야 한다.

| ID | 검사 | 통과 판정 |
|---|---|---|
| P1-1 | 타 아동·집단 부재 | 다른 아이의 세션·사례·표·분포·"실제 N개" 류가 일절 없음 |
| P1-2 | 규준·통계 부재 | 또래·평균·백분위·기준선·규준·상위% 어휘와 시각 요소(기준 링·평균선) 없음 — 공시문에서 이를 부정하는 문장만 예외 |
| P1-3 | 서열 어휘 부재 | "등수·순위·상위·하위·비교" 류 없음. 아이 내부 배치(대표 강점/함께 빛난 힘)는 허용 |
| P1-4 | 숫자의 자기 기준성 | 인쇄되는 모든 숫자는 발휘도 85~100뿐이며, 공시문이 아이 자신 기준 상대 지수임을 명시 |

## P2. 비어보임·부족해보임·옅어보임 금지 (50점)

어떤 데이터에서 뽑아도, 어느 요소도 "덜한 것·빠진 것·죽은 것"으로 읽히면 안 된다.

| ID | 검사 | 통과 판정 |
|---|---|---|
| P2-1 | **페이드 금지** | 데이터를 표현하는 요소(조각·막대·숫자·이름·칩)에 투명도 저하·회색화·톤 다운 없음. 모든 채움은 완전 불투명한 실색. 밝은 색은 허용하되 "바랜 색·비활성 스타일"로 읽히는 처리는 금지 |
| P2-2 | 완전한 형태 | 7조각 전부 채워진 웨지로 그려짐. 점선·빈 조각·구멍·중심 붕괴 없음. 흰 배경 고정 |
| P2-3 | 숫자 전원 존재·동급 | 7축 모두 85~100 숫자가 있고, 기본값 축의 숫자도 같은 서체·같은 크기·완전한 색(대표 강점의 강조 확대만 예외) |
| P2-4 | 결핍 어휘 금지 | "부족·못한·없음·미관측·기록 없음·아직·놓친·비어" 류가 부모 화면에 없음 — 부정문("부족이 아니라")으로도 등장 금지. 기본값 축은 전향 표현("곧 피어날 힘")만 사용 |
| P2-5 | 강점 부각 | 대표 강점이 크기·색·배치에서 가장 도드라지고, 잘한 것 서술이 리포트 상단부에 옴 |
| P2-6 | 최악 케이스 방어 | 관측 1축뿐인 세션 렌더에서도 위 P2-1~P2-5가 전부 성립 (억지로 그릴 수 없는 관측 0축은 리포트 미생성) |

## 채점

100점 시작, 위반 1건당 P1 항목 −10~−25, P2 항목 −5~−20(심각도), 재현 증거 필수. **감점 0건일 때만 100.**

정직성 하한(감점과 무관하게 유지): 발휘도 공시문, DEMO DATA 배지, "정식 검사 아님" 문구, 인용 스코프 문구는 삭제 금지 — 이들은 결핍 표현이 아니라 신뢰 장치다.

- 2026-08-21: 독립 인상 심판(Sonnet 5) 1라운드 100/100 — P1·P2 전 항목 통과, 감점 0. 판정 근거: 데이터 요소 전부 완전 불투명 실색(setFillAlpha(1) 강제, CSS 투명도/점선 0건), 기본값 85 숫자가 관측 숫자와 동일 서체·크기·색, 7/7 웨지 채움(최악 1축 케이스 포함), 비교 어휘는 부정 공시문 1곳뿐, 코호트 코드가 부모 렌더러에 도달하지 않음을 소스로 확인.
